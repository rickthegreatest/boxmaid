A SMALL TOOL THAT GOES WHERE YOU WORK

How do I start?

Install the Go CLI, or grab a prebuilt binary for Linux, macOS, or Windows.

go install github.com/rickthegreatest/boxmaid/cmd/boxmaid@latest
boxmaid -w 80 -color never -require-fit diagram.mmd

Go CLI: Go 1.22+ · Bubble Tea module: Go 1.24+ · Rust: 1.88+

Want to embed it? Start with the Go API or Rust API.
