# What is new in Boxmaid 0.1.1?

This patch polishes the first release's public documentation and package links:

- Rust API documentation now points to `github.com/rickthegreatest/boxmaid` and accurately describes width fitting as best-effort.
- docs.rs builds include the optional Ratatui widget documentation.
- The README and showcase link the published Go/Rust packages and launch discussion.

## How do I install it?

```sh
go install github.com/rickthegreatest/boxmaid/cmd/boxmaid@v0.1.1
# Or:
cargo install boxmaid --version 0.1.1 --locked
```

Prebuilt archives are available for Linux, macOS, and Windows on amd64 and arm64. Verify downloads against `SHA256SUMS`.
